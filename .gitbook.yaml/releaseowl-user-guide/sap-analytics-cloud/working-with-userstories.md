# Working with UserStories

* Navigate to the **Change Management** section.
* Go to **User Stories**, click on the **Create New User Story**.

<img src="https://releaseowl.gitbook.io/releaseowl-docs/~gitbook/image?url=https%3A%2F%2F1890383800-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FDWyxe6hm5vqosFaByVgs%252Fuploads%252FyzQqMWbt6oZ3AYYcnNYJ%252Fimage.png%3Falt%3Dmedia%26token%3Ddbc8be9c-8e07-4e6e-bcbb-7e6d54772ddc&#x26;width=768&#x26;dpr=3&#x26;quality=100&#x26;sign=dcd3f89d&#x26;sv=2" alt="" height="898" width="1896">

* Fill in the required fields, such as:
  * **Summary**: A clear and concise name for the user story.
  * **Description**: Detailed explanation of the requirement or feature.
  * **Release Version**, **Sprint**, **Assigned To**, and any other custom fields as applicable.
* After entering the details, click the **Save** button to create the User Story.

<img src="https://releaseowl.gitbook.io/releaseowl-docs/~gitbook/image?url=https%3A%2F%2F1890383800-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FDWyxe6hm5vqosFaByVgs%252Fuploads%252FFFoOsEPzSFsjhF15UcUu%252Fimage.png%3Falt%3Dmedia%26token%3Dafa74edb-d117-4770-ad03-2e0ced554b9c&#x26;width=768&#x26;dpr=3&#x26;quality=100&#x26;sign=824a7bcc&#x26;sv=2" alt="" height="907" width="1887">

* Once the User Story is created, it will appear in the list/grid view.
* Click on the **Edit** next to the User Story entry.

<img src="https://releaseowl.gitbook.io/releaseowl-docs/~gitbook/image?url=https%3A%2F%2F1890383800-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FDWyxe6hm5vqosFaByVgs%252Fuploads%252FSsDEJGMKEnOYYCTeVYFZ%252Fimage.png%3Falt%3Dmedia%26token%3Db20560f3-6d0c-4901-b789-fdfd062f56d2&#x26;width=768&#x26;dpr=3&#x26;quality=100&#x26;sign=f18463c5&#x26;sv=2" alt="" height="911" width="1899">

* Click on the **+Add** button to add **SAC Packages**.
* Click the **three-dot (More Actions)** menu.
* Select **Import Settings**.

<figure><img src="../../.gitbook/assets/image (2200).png" alt=""><figcaption></figcaption></figure>

* Click on the **Save** button.

{% hint style="info" %}
**Note:  Force Deploy** — lets you redeploy the artifacts/agreements again even if it was already deployed.

* When _Force Deploy_ is enabled, version validation checks do not block the deployment.
* If the target environment version is higher than the source environment version, a warning message is displayed.
{% endhint %}

**Promote User Story:**

* Click on **Promote** to promote the user story.
