# SAP ABAP Cloud

ReleaseOwl provides native, end-to-end CI/CD and change management for SAP BTP ABAP Environment (“Steampunk”) applications built using the RESTful ABAP Programming (RAP) model, with source code maintained in Git.&#x20;

This guide describes how to create and configure a RAP Application, attach it to a user&#x20;story, and run it through its own release-pipeline tasks — checkout, merge, validate, and deploy.&#x20;

#### **Supported Git providers**&#xD;

RAP applications can be sourced from any of the following version control systems:



* Bitbucket
* GitHub
* Azure DevOps
* GitLab
